# Mind Space AI 🧠🚀

**Mind Space AI** is a cutting-edge, AI-powered "memory hub" designed to revolutionize how you capture and organize information. Built with **React**, **Tailwind CSS**, and **Google's Gemini AI**, it serves as an intelligent assistant that doesn't just store your data but understands it.

> [!IMPORTANT]
> **Status**: This application is currently a **Work in Progress (WIP)** and is **not yet fully functional**. Some features may be incomplete or experimental as development continues.

## ✨ Features

- **AI-Powered Capture**: Instantly extract key insights from notes, links, and snippets using Gemini.
- **Smart Categorization**: Automatically organize your "memories" into collections based on content.
- **Intelligent Summarization**: Get high-level overviews of your stored information without manual effort.
- **Sleek UI/UX**: A modern, responsive interface built with glassmorphic elements and smooth micro-animations.
- **Real-time Search**: Quickly retrieve anything from your digital mind-space.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **AI Engine**: [Google Gemini SDK](https://ai.google.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/cloud9890/mind-space-ai.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up Gemini API Key**:
   Create a `.env` file and add your key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
4. **Run the dev server**:
   ```bash
   npm run dev
   ```

## 🧠 How it Works

Mind Space AI leverages the power of Large Language Models to act as a second brain. When you add a new memory, the Gemini service analyzes the text, determines the most relevant category, and generates a concise summary, making information retrieval effortless.
